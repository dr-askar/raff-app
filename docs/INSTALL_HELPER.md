# مساعد تثبيت رفّ

أداة مستقلة اسمها «مساعد تثبيت رفّ»، وليست إصداراً جديداً من برنامج المحل.
تتضمن ملف رفّ 0.4.1 المنشور نفسه، دون تعديل هويته أو توقيعه أو بياناته.

## الاستخدام

1. ثبّت المساعد وافتحه.
2. اضغط «تثبيت رفّ وإظهار النتيجة». إذا طلب أندرويد سماح التثبيت لهذا المصدر،
   امنحه من نافذة الإعداد النظامية ثم ارجع واضغط الزر. لا تعطل حماية الهاتف.
3. وافق على نافذة التثبيت. عند النجاح يظهر «فتح رفّ»؛ عند الفشل يعرض المساعد
   رمز أندرويد والنص التفصيلي. يكفي تصوير تلك النتيجة، دون كمبيوتر أو USB.

## ما يفعله

- يطابق SHA-256 للملف المضمّن قبل تسليمه إلى PackageInstaller، ويتحقق من
  الحزمة `com.raffapp.raff` ورقم البناء 9. البصمة:
  `5857b79d51300d3de282dd4454d0fab6a74e1c9c21bdb7d0fd2f703d817f6926`.
- يحفظ `EXTRA_STATUS` و`EXTRA_STATUS_MESSAGE` ورمز PackageManager القديم
  كما أرسلها أندرويد؛ يعرض النتائج بالعربية مع النص الأصلي.
- يعرض إصدار أندرويد، موديل الهاتف، المعماريات ونسخة رفّ الظاهرة للمستخدم الحالي.
  عدم ظهور رفّ لهذا المستخدم لا يثبت غيابه عن المستخدمين أو المساحات الأخرى.
- لا يحذف رفّ، لا يمسح بياناته، لا يغير هويته، لا يفرض خفض إصدار، ولا يعطل فحص النظام.
- لا يحتاج الإنترنت أو صلاحية الملفات العامة أو حسابات أو كاميرا أو بيانات المحل.
  لا يرسل أي تقرير. زر النسخ ينسخ النتيجة للحافظة بطلب المستخدم فقط.
- تطبيق Java صغير بلا Flutter أو مكتبات أصلية؛ حجمه ناتج عن تضمين APK رفّ
  كي لا يحتاج المستخدم اختيار ملف أو تنزيله مرة أخرى.

المساعد نفسه يحتاج موافقة مثبت أندرويد كي يثبت أولاً. إذا مُنع هو أيضاً، فلا
تتوفر منه نتيجة تشخيصية؛ لا يُدّعى حل سبب الرفض. وقد تعطي واجهة شاومي نتيجة
مختلفة عن PackageInstaller؛ نجاح هذا المسار وحده لا يفسر المسار الآخر.

## التحقق

يبني workflow `install-helper.yml` المساعد بمفتاح الإصدار الثابت، ويتحقق من
التوقيع ومطابقة APK المضمّن. يختبر الموافقة النظامية والتثبيت وفتح رفّ، ثم
إعادة التثبيت مع مقارنة ملف SharedPreferences الفعلي. يثبت نسخة مستقبلية
اصطناعية في المحاكي فقط ليتأكد من أن رفض خفض الإصدار الحقيقي يظهر في الواجهة
وأن الحزمة والبيانات لم تحذف. ملف الاختبار الاصطناعي لا ينشر للمستخدم.
نتائج التشغيل المحددة توثق بعد اكتماله؛ لا يعد وصف الفحص دليلاً على نجاحه.
