## ملف Products الجديد

| العمود | المعنى |
|---|---|
| id | معرف ثابت للمطابقة، يترك فارغاً عند إضافة صنف جديد |
| اسم المادة، الباركود، التصنيف | بيانات الصنف؛ الباركود نص يحافظ على الأصفار |
| نوع الصنف | طرد أو وزن؛ الخانة الفارغة طرد |
| عدد القطع بالطرد | محتوى الطرد من القطع للأصناف غير الموزونة |
| عدد الطرود | عدد الطرود الكاملة المتوفرة؛ يقبل كسر طرد عند الإدخال |
| قطع إضافية | قطع خارج الطرود الكاملة، حتى لا يضيع مخزون الطرد المفتوح |
| وزن الطرد بالكيلوغرام | وزن عبوة الصنف الموزون؛ يقبل الكسور |
| الكمية بالكيلوغرام | المخزون الفعلي للصنف الموزون؛ يقبل الكسور |
| سعر الطرد | تكلفة الطرد كاملة، وليس تكلفة القطعة أو الكيلو |
| عملة التكلفة | USD أو SYP؛ دولار أو سوري مقبولان أيضاً |
| نسبة الربح، نسبة المساومة | نسب مئوية؛ لا يتغير معناها |
| سعر مبيع الطرد الثابت | اختياري، سعر بيع كامل الطرد محلياً؛ يقسم داخلياً على محتواه |
| سعر مبيع الطرد، سعر الصرف | للعرض فقط؛ السعر التلقائي يحسب داخل البرنامج |

للطرود: الكمية الداخلية = عدد الطرود × عدد القطع بالطرد + القطع الإضافية.
إذا أدخل أحد حقلي العدد أو القطع الإضافية وترك الآخر فارغاً، يعامل الآخر بصفر.
إذا ترك الاثنان فارغين عند تحديث صنف، تبقى كميته السابقة. خانة السعر الفارغة
تحافظ على التكلفة السابقة؛ الصفر سعر صريح. الصنف الجديد باسم فقط مقبول.

للوزن: الكمية بالكيلوغرام مستقلة عن وزن العبوة. يمكن استيراد عدد طرود بدل
كمية الكيلو، فتضرب في وزن العبوة؛ لا تملأ الطريقتين بقيم مختلفة. يصدّر البرنامج
الكمية بالكيلو، لا القطع الإضافية. تكلفة الكيلو = سعر العبوة ÷ وزنها.
لا يوجد تحويل للعملة السورية عند تغيير سعر الدولار.

## أمثلة

- 3 طرود، كل طرد 6 قطع، وقطعتان إضافيتان، وسعر الطرد 30 USD:
  المخزون 20 قطعة، وتكلفة القطعة داخل البرنامج 5 USD.
- طرد 12 قطعة بسعر 120000 SYP: تكلفة القطعة 10000 SYP.
- عبوة رز وزنها 12.5 كغ بسعر 25000 SYP، والمخزون 0.125 كغ:
  يحتفظ الملف بالوزن والكمية كما هما، وتكلفة الكيلو داخل البرنامج 2000 SYP.

## الملفات القديمة

تبقى أسماء pack وquantity وcost_usd وcost_syp وmanual_price مقبولة بمعانيها
السابقة: كمية وسعر للوحدة، لا للطرد. لا نغير تفسير cost_usd=5 إلى سعر طرد 5؛
مع pack=6 تبقى تكلفة الطرد 30. للتعامل بالطرود صدّر ملفاً جديداً من 0.4.2.
يمكن أيضاً استيراد cost_per_pack أو «سعر الطرد بالدولار/بالسوري».
الصف المتعارض أو غير الصالح يحذّر عنه وحده، ولا يوقف بقية الأصناف.
لم يتغير تخزين JSON الداخلي ولا تقرير الجرد؛ لا تعاد قسمة البيانات القديمة.

أضيفت فحوص للأمثلة أعلاه، تعديل ملفات مصدّرة، الخانات الفارغة والصفر، توافق
الملفات القديمة، عزل التعارضات، و1200 صنف طرد ووزن في ورقة واحدة.
