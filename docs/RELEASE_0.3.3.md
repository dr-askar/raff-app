# رفّ 0.3.3 — إصلاح استيراد Excel

يعالج الإصدار ملفات XLSX التي تحتفظ بنصوص مكررة داخل sharedStrings.xml بعد التعديل. كانت مكتبة القراءة تغيّر الفهرس، فتفشل المعاينة أو تُقرأ نصوص مختلفة. تُحل مراجع الخلايا الآن من الجدول الأصلي قبل فك الملف، ولا تتغير أسماء الأصناف أو القيم بسبب إعادة فهرسة النصوص.

اختبارات الإصدار: ملف صناعي يحاكي 113 صنفاً و192 مدخلاً مكرراً، واستيراد 1200 صنف في ورقة واحدة والتحقق من كل صنف بعد إعادة فتح التخزين. جميع الصفوف الصالحة تُعالج دون سقف عددي؛ حد الملف 5MiB وبعد فك الضغط 50MiB لحماية ذاكرة الهاتف.

## التثبيت والانتقال

ملف APK موحد يتطلب Android 7 أو أحدث. هذه نسخة محلية دون إعداد مزامنة Firebase. ملفات المواد لا تنقل كلمة سر المدير أو صلاحيات العامل.

التوقيع تجريبي وليس مفتاح إصدار دائم. قد يرفض Android التحديث فوق نسخة بتوقيع آخر. قبل إزالة نسخة فيها بيانات، صدّر نسخة JSON واحفظها خارج التطبيق وتأكد من وجودها. بعد التثبيت الجديد استرجعها واضبط كلمة سر المدير وصلاحيات العامل مجدداً. إذا لا توجد بيانات مطلوبة يمكن الانتقال إلى تثبيت جديد.

مفتاح إصدار دائم محفوظ في GitHub Secrets ما زال مطلوباً لتحديثات مستقرة؛ لا تحفظ المفاتيح الخاصة في المستودع أو الكاش العام.

يُنشر رابط APK بعد نجاح التحليل والاختبارات وفحوص ZIP والتوقيع والمكتبات الأصلية وتجارب التثبيت والفتح على محاكيات Android 7 و11 و15 و16 و17 (16KB). محاكيات الاختبار لا تضمن كل إعدادات أجهزة الشركات أو الكاميرا على الهاتف الفعلي.
