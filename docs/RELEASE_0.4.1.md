# رفّ 0.4.1 — ملف تجريبي بتوقيع إصدار ثابت

- شريط صرف أصغر لإظهار مواد أكثر.
- صلاحية مستقلة لاستعادة النسخة للعامل، تشمل الملفات وDrive ولا تمنح التصدير أو رؤية رأس المال.
- إدخال سعر الطرد بالدولار أو السوري ومحتواه وحساب تكلفة القطعة أو الكغ تلقائياً.
- اختيار طرد/وزن. خلية النوع الفارغة في Excel تعني طرداً؛ غياب العمود في الملفات القديمة يحافظ على نوع المادة الموجودة.

مصدر التطبيق اجتاز 68 اختبار Flutter و17 اختبار قواعد Firebase. هذا الملف يُوقّع
بمفتاح إصدار ثابت، مع فحص بصمته وتطابق محتوى التطبيق قبل وبعد التوقيع وفحص
التثبيت والفتح والترقية بالبيانات على محاكيات Android 7 و11 و15 و16 و17.
فحص الترقية يستخدم نسخة 0.4.0 أُعيد توقيعها بالمفتاح نفسه للاختبار فقط؛ النسخ
التجريبية القديمة المنشورة بتواقيع مختلفة لا يمكن تحديثها بهذا المفتاح مباشرة.

Android 7 أو أحدث، ملف واحد ARM32 وARM64 وx86_64. لا تتضمن النسخة مزامنة Firebase
مهيأة للمحل. نجاح المحاكيات لا يثبت حل رفض التثبيت على هاتف Xiaomi الفعلي؛
تبقى المشكلة مفتوحة حتى نجاح تجربته. لا تحذف تطبيقاً يحتوي بيانات قبل حفظ JSON
والتأكد من وجوده خارج التطبيق.
