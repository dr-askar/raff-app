# حالة التحقق

نفذت في بيئة إعداد المشروع:

- نجاح `bash -n scripts/bootstrap.sh`.
- نجاح تجميع سكربت Python الإعداد باستخدام `py_compile`.
- نجاح فحص بنية JavaScript باستخدام `node --check test/firestore_rules.test.mjs`.
- نجاح قراءة ملفات JSON الثلاثة: إعداد Firebase، قالب إعداد العميل، وتعريف اعتماديات اختبارات القواعد.
- فحص بنيوي للأقواس والسلاسل النصية في ملفات Dart وقواعد Firestore. هذا فحص أولي، وليس بديلاً عن المحلل أو المترجم.
- تجربة سكربت إعداد Android على ملفات Manifest وGradle مؤقتة والتحقق من الإذن والاسم والحد الأدنى للنظام.

نفذت على GitHub Actions بعد رفع المشروع وإصلاح تجاوز رسالة السلة الفارغة لمساحة الشاشة:

- نجاح تثبيت الاعتماديات و`flutter analyze` دون ملاحظات.
- نجاح `flutter test`: جميع الاختبارات الـ18، بما فيها البحث على شاشة هاتف أثناء ظهور لوحة المفاتيح.
- نجاح اختبارات محاكي Firestore: جميع الاختبارات الـ6، بما فيها صلاحيات العامل وإغلاق الجرد.
- نجاح بناء APK تجريبي موحد (حوالي 79 ميغابايت)، يدعم ARM 32 بت وARM64 وx86_64 على Android 7 وأحدث.
- تعثّر نشر الملف ضمن تشغيل البناء بسبب صلاحية إنشاء إصدار من مصدر تجاوزته تعديلات لاحقة؛ أعيد استخدام ملف البناء نفسه ونشره بنجاح في خطوة مستقلة، دون تغيير التطبيق.
